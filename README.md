# Automated Sales Dashboard for Hardware Business 📊💻

This project involves creating an **automated dashboard** for a computer hardware business that was facing scaling challenges and lacked actionable insights. The dashboard provides a comprehensive, data-driven overview to support strategic decision-making.

---

## 🧠 Project Summary

- Developed a dynamic and interactive dashboard using **Power BI**.
- Analyzed sales data using **SQL** to extract trends and KPIs.
- Monitored revenue growth, YOY trends, and region-wise sales performance.
- Enabled business leaders to make quick, data-informed decisions.
- Projected a **7% revenue increase** in the upcoming quarter due to improved visibility and responsiveness.

---

## 🚀 Key Features

- 📈 Real-time sales trends visualization
- 🌍 Region-wise performance heatmaps
- 📊 YOY revenue comparisons
- 📤 Exportable summary reports
- ⏱️ Automated data refresh and scheduled updates
